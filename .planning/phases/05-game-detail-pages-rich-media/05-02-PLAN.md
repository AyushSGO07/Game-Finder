<threat_register>
- Threat ID: T-5-04
  Category: Denial of Service / Video Player Crash on Broken Media
  Component: TrailerPlayer Component
  Severity: Low
  Disposition: Mitigate
  Mitigation Plan: Provide both MP4 and WebM fallback source tags, defensive `onError` handlers, and poster image placeholders when video fails to load.

- Threat ID: T-5-05
  Category: Memory Leak / Key Listener Leak
  Component: ScreenshotLightbox Component
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Ensure `window.removeEventListener('keydown')` cleanup in `useEffect` unmount handler, lock background body scrolling safely, and trap focus inside the modal dialog.

- Threat ID: T-5-06
  Category: Route Param Tampering / 404 Crash
  Component: app/games/[id]/page.tsx
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Sanitize route parameter, render clean 404 "Game Not Found" screen with link back to discovery hub when game is not found, avoiding unhandled 500 exceptions.
</threat_register>
</threat_model>
