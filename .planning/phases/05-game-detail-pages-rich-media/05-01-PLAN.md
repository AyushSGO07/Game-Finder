<threat_model>
<trust_boundaries>
- External Steam API Metadata vs. Client Browser DOM.
- User Game ID Parameter vs. Backend API Request.
- Raw HTML in System Requirements vs. React Inner HTML.
</trust_boundaries>

<threat_register>
- Threat ID: T-5-01
  Category: Denial of Service / Invalid Parameter Injection
  Component: fetchGameDetails API Client
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Validate and sanitize game identifier string/number, enforce 3000ms timeout on network requests, and fallback to verified mock game detail objects.

- Threat ID: T-5-02
  Category: Broken Link / Insecure External Redirect
  Component: GameSidebar & GameHeader External Store Links
  Severity: Low
  Disposition: Mitigate
  Mitigation Plan: Enforce `rel="noopener noreferrer"` and `target="_blank"` on all external Steam and official website hyperlinks.

- Threat ID: T-5-03
  Category: Cross-Site Scripting (XSS)
  Component: SystemRequirements Component
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Never render untrusted external HTML directly using `dangerouslySetInnerHTML`. Parse and strip HTML tags into structured text key-value pairs (OS, Processor, Memory, Graphics, Storage) or sanitize safe tags.
</threat_register>
</threat_model>

<task id="5-01-01" wave="1">
<title>Augment GameDetail Types, Curate Detail Mocks, and Implement fetchGameDetails API Client</title>
<description>
Update domain models and data fetchers in `frontend/src/`:
- In `frontend/src/types/game.ts`:
  - Define `ScreenshotItem`: `id: number`, `path_thumbnail: string`, `path_full: string`.
  - Define `MovieItem`: `id: number`, `name: string`, `thumbnail: string`, `mp4_url?: string`, `webm_url?: string`.
  - Augment `GameDetail`: `id`, `steam_appid`, `title`, `header_image`, `capsule_image`, `hero_image`, `short_description`, `detailed_description`, `about_the_game`, `genres`, `developers`, `publishers`, `release_date`, `rating`, `screenshots: ScreenshotItem[]`, `movies: MovieItem[]`, `pc_requirements?: Record<string, string>`, `website?: string`, `steam_url?: string`, `platforms?: string[]`.
- In `frontend/src/lib/mockData.ts`:
  - Add `MOCK_GAME_DETAILS`: Dictionary keyed by AppID / slug containing rich detail models for Elden Ring (`1245620`), Cyberpunk 2077 (`1091500`), and Baldur's Gate 3 (`1086940`), with verified screenshot URLs, trailer video streams, and PC system specs.
  - Add fallback default detail generator for arbitrary unknown IDs.
- In `frontend/src/lib/api.ts`:
  - Implement `fetchGameDetails(id: string | number): Promise<GameDetail | null>`.
  - Queries `GET /api/v1/games/{id}` with timeout safety (`3000ms`).
  - Falls back to `MOCK_GAME_DETAILS[id]` or default mock detail if backend is unreachable.
- Create `frontend/src/__tests__/GameApi.test.tsx` verifying successful detail retrieval, fallback behavior on unknown IDs, and valid schema structures.
</description>
<verification>
Run `npm --prefix frontend test -- src/__tests__/GameApi.test.tsx` to verify API client tests pass.
