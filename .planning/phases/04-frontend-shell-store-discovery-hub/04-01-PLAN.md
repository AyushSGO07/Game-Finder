<description>

  - Define border tokens: `border-glass` (`rgba(255, 255, 255, 0.08)`), `border-glass-hover` (`rgba(99, 102, 241, 0.4)`).

  - Define root layout with `min-h-screen bg-[#090a0f] text-slate-100 antialiased selection:bg-indigo-500/30 selection:text-indigo-200`.
  - Include metadata for Game Finder (title, description).
  - Provide container shell `<main id="main-content" className="flex-1 pb-16">` ready for persistent navigation and content insertion.

<task id="4-01-03" wave="1">
<title>Implement Frontend Domain Types, Discovery Mock Datasets, and Resilient API Client</title>
<description>
Create typed domain models, curated discovery datasets, and backend API integration:
- In `frontend/src/types/game.ts`:
  - Define `GameCard`: `id`, `steam_appid`, `title`, `header_image`, `capsule_image`, `hero_image`, `genres`, `rating`, `release_date`, `developer`, `short_description`, `price`.
  - Define `HeroSlide`: `id`, `title`, `backdrop_url`, `logo_url`, `rating`, `genres`, `synopsis`, `store_url`.
  - Define `ShelfCategory`: `'featured' | 'trending' | 'new_releases' | 'top_rated' | 'hidden_gems'`.
  - Define `GenreTile`: `id`, `name`, `slug`, `icon`, `gradient`, `description`.
- In `frontend/src/lib/mockData.ts`:
  - Curate high-fidelity mock datasets for Hero carousel (6 games e.g. Elden Ring, Cyberpunk 2077, Baldur's Gate 3, Hades II, Hollow Knight: Silksong, Clair Obscur: Expedition 33) with verified Steam backdrop CDNs.
  - Curate shelf datasets: Trending (6 games), New Releases (6 games), Top Rated (6 games), Hidden Gems (6 games).
  - Define 12 Genre Tiles: Action, RPG, Adventure, Shooter, Horror, Strategy, Simulation, Racing, Sports, Indie, Puzzle, Platformer.
- In `frontend/src/lib/api.ts`:
  - Implement async client functions: `fetchHeroGames()`, `fetchShelfGames(category)`, `fetchGenres()`, `searchGames(query)`.
  - Try fetching from FastAPI backend (`NEXT_PUBLIC_API_URL` or `http://localhost:8000/api/v1`).
  - Gracefully fallback to `mockData.ts` if backend is unreachable, times out (>3s), or returns non-200, guaranteeing visual continuity.
- Create `frontend/src/__tests__/Api.test.tsx` testing successful fallback on network failure and correct schema shapes.
</description>
<verification>
Run `npm --prefix frontend test -- src/__tests__/Api.test.tsx` to verify domain data and fallback mechanics pass.
</verification>
