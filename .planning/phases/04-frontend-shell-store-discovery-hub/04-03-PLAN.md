  Category: Uncontrolled Animation / Accessibility / Focus Traps in Carousel
  Component: HeroCarousel
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Provide pause-on-hover and pause-on-focus listeners, clean up interval timers on component unmount, support reduced motion media queries, and include accessible ARIA controls.

- Threat ID: T-4-08
  Category: Horizontal Scroll Overflow / Broken Image Injection
  Component: GameShelf & GameCard
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Implement defensive image onError fallbacks to SVG placeholders, enforce scroll bounds on chevron click handlers, and prevent layout shifts with fixed aspect ratios.

- Threat ID: T-4-09
  Category: Genre Filter Injection / Missing Category Fallbacks
  Component: GenreHub & Home Page Assembly
  Severity: Low
  Disposition: Mitigate
  Mitigation Plan: Validate genre slugs against strict enum set (Action, RPG, Strategy, etc.), escaping query parameters before route navigation.
</threat_register>
