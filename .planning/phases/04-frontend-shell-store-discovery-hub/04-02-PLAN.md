<threat_register>
- Threat ID: T-4-04
  Category: Broken Navigation / Route Disconnect
  Component: Desktop Navbar
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Enforce typed route constants for canonical navigation targets (`/`, `/discover`, `/finder`, `/goty`, `/library`), active link highlighting, and semantic HTML `<nav>` tags.

- Threat ID: T-4-05
  Category: Mobile Touch Event Hijacking / Layout Breakage
  Component: MobileNav Drawer
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Maintain strict drawer open/closed state isolation, prevent background scroll leakage when drawer is open (`overflow: hidden`), and enforce minimum 44px tap targets.

- Threat ID: T-4-06
  Category: Client-Side Search Query Injection / XSS
  Component: SearchModal
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Sanitize query strings, avoid dangerouslySetInnerHTML, handle keyboard shortcuts safely, and ensure proper focus trap and Escape key dismissal.
</threat_register>
</threat_model>
