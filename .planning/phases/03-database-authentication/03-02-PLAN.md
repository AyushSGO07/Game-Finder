<threat_register>
- Threat ID: T-3-04
  Category: Spoofing / Authentication Bypass
  Component: JWT Token Decoding & Validation
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Verify JWT signatures and claims (expiration `exp`, audience `aud`, and subject `sub`), rejecting expired, malformed, or untrusted tokens with HTTP 401 Unauthorized.

- Threat ID: T-3-05
  Category: Information Disclosure
  Component: Password & Secret Handling
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Use write-only `SecretStr` in Pydantic models for user passwords, exclude password hashes from all serialization responses, and ensure Supabase service keys are never leaked to responses.

- Threat ID: T-3-06
  Category: Elevation of Privilege
  Component: Protected User Library Endpoints (/api/v1/me/*)
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Enforce `get_current_user` dependency injection on all `/api/v1/me/*` routes, scoping all database queries and mutations strictly to the authenticated `user.id`.
</threat_register>
</threat_model>

<task id="3-02-01" wave="2">
<title>Define Auth, Profile, and Library Pydantic Schemas</title>
<description>
Create `backend/app/schemas/auth.py` defining data contracts:
- `UserRegisterRequest`: email (EmailStr), password (min length 8), username (3-20 alphanumeric/underscore), display_name (optional).
- `UserLoginRequest`: email (EmailStr), password (str).
- `TokenResponse`: access_token (str), refresh_token (Optional[str]), token_type (str = "bearer"), expires_in (int).
- `UserProfileResponse`: id, username, display_name, avatar_url, bio, favorite_genres, preferred_platforms, default_difficulty, default_age_rating, is_public, show_library, show_favorites, show_reviews, show_rankings, created_at, updated_at.
- `UserProfileUpdate`: partial update model for profile bio, avatar, preferences, and privacy flags.
- `UserLibraryItemCreate`: game_id (str/uuid), status (Optional[str] from wishlist, backlog, playing, completed, dropped), is_favorite (bool = False), personal_rating (Optional[int] 1-10), playtime_hours (float = 0.0), notes (Optional[str]).
- `UserLibraryItemUpdate`: partial update model for status, rating, rank, playtime, notes, is_favorite.
- `UserLibraryItemResponse`: full model including game metadata summary (title, cover_url, slug).
- `RankedListUpdate`: list of ranked game positions `[{"game_id": "...", "rank": 1}]`.
- `ReviewCreateRequest`: game_id, rating (1-10), title (optional), body (str).
Export schemas in `backend/app/schemas/__init__.py`.
Create `backend/tests/test_auth_schemas.py` to verify valid input validation, password constraints, and serialization.
</description>

<task id="3-02-02" wave="2">
<title>Implement Supabase Service Client, Config Updates, and JWT Auth Dependency</title>
<description>
Update `backend/requirements.txt` with `supabase>=2.10.0` and `pyjwt[crypto]>=2.9.0`.
Update `backend/app/core/config.py`:
- Add `SUPABASE_URL: str = ""`
- Add `SUPABASE_ANON_KEY: str = ""`
- Add `SUPABASE_SERVICE_ROLE_KEY: str = ""`
- Add `SUPABASE_JWT_SECRET: str = ""`

Create `backend/app/services/supabase_service.py`:
- Initializes Supabase client when credentials are present; provides robust mocked/in-memory adapter for offline unit testing.
- Methods: `sign_up(email, password, metadata)`, `sign_in_with_password(email, password)`, `sign_out(token)`, `get_user_by_token(token)`.
- Database query helpers for `profiles`, `user_games`, `reviews`, and `ranked_lists`.

Create `backend/app/core/auth.py`:
- `get_current_user(credentials = Depends(HTTPBearer())) -> AuthenticatedUser`:
  - Decodes JWT token using `pyjwt` or Supabase Auth.
  - Verifies token validity, expiration, and user ID claim.
  - Returns `AuthenticatedUser(id=user_id, email=email, role=role)`.
  - Raises `HTTPException(status_code=401, detail="Invalid authentication credentials")` on invalid/expired tokens.
- `get_optional_user(...) -> Optional[AuthenticatedUser]`:
  - Allows optional authentication for public discovery personalization.

Create `backend/tests/test_auth_service.py` to test JWT decoding, mock sign-in, token expiration rejection, and current user extraction.
</description>

<task id="3-02-03" wave="2">
<title>Implement FastAPI Auth & User Library API Routes and Integration Tests</title>
<description>
Create `backend/app/api/v1/auth.py`:
- `POST /api/v1/auth/register`: registers user via SupabaseService, auto-provisions profile, returns `TokenResponse` and profile.
- `POST /api/v1/auth/login`: verifies credentials, returns `TokenResponse`.
- `POST /api/v1/auth/logout`: invalidates session token.
- `GET /api/v1/auth/me`: requires `Depends(get_current_user)`, returns user profile and account details.

Create `backend/app/api/v1/library.py`:
- `GET /api/v1/me/profile`: returns profile for current user.
- `PATCH /api/v1/me/profile`: updates current user profile preferences and privacy toggles.
- `GET /api/v1/me/library`: returns library items filtered by status (`wishlist`, `backlog`, `playing`, `completed`).
- `POST /api/v1/me/library/{game_id}`: adds or updates game in user library.
- `DELETE /api/v1/me/library/{game_id}`: removes game from library.
- `GET /api/v1/me/favorites`: returns user favorite games.
- `POST /api/v1/me/favorites/{game_id}`: toggles favorite flag for game.
- `GET /api/v1/me/rankings`: returns user Top 10 ranked list.
- `POST /api/v1/me/rankings`: saves reordered Top 10 list.

Integrate both routers into `backend/app/main.py`:
- Mount `auth.router` at `/api/v1/auth` (tag: "auth").
- Mount `library.router` at `/api/v1/me` (tag: "user-library").

Create `backend/tests/test_auth_api.py` and `backend/tests/test_library_api.py`:
- Integration tests using FastAPI `TestClient` verifying register, login, 401 unauthorized access, profile updates, library shelving, favorites toggle, and ranking reordering.
</description>
