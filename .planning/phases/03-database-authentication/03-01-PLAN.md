<threat_register>
- Threat ID: T-3-01
  Category: Tampering / Elevation of Privilege
  Component: PostgreSQL Tables (user_games, reviews, ranked_lists, profiles)
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Enforce Row-Level Security (RLS) policies checking `auth.uid() = user_id` on all INSERT, UPDATE, and DELETE operations.

- Threat ID: T-3-02
  Category: Information Disclosure
  Component: User Profile and Library Records
  Severity: High
  Disposition: Mitigate
  Mitigation Plan: Guard SELECT queries on `profiles`, `user_games`, and `ranked_lists` with `is_public` and `show_library`/`show_rankings` flags so private gamer records cannot be viewed by unauthorized users.

- Threat ID: T-3-03
  Category: Denial of Service / Integrity Violation
  Component: Relational Constraints & Cascade Deletes
  Severity: Medium
  Disposition: Mitigate
  Mitigation Plan: Define ON DELETE CASCADE on all foreign key constraints referencing `auth.users(id)` and `games(id)` to prevent orphaned records and cascading constraint lockups.
</threat_register>
</threat_model>

<task id="3-01-02" wave="1">
<title>Define Row-Level Security Policies, Triggers & Seed Migrations</title>
<description>
Create `supabase/migrations/20261007000001_rls_policies.sql`:
- Enable Row-Level Security on all tables: `ALTER TABLE ... ENABLE ROW LEVEL SECURITY;`.
- Policies for `profiles`:
  - SELECT: `is_public = true OR auth.uid() = id`
  - INSERT: `auth.uid() = id`
  - UPDATE: `auth.uid() = id`
  - DELETE: `auth.uid() = id`
- Policies for `games`, `game_media`, and `goty_winners`:
  - SELECT: `true` (public readable)
  - INSERT/UPDATE/DELETE: `auth.role() = 'service_role'`
- Policies for `user_games`:
  - SELECT: `auth.uid() = user_id OR EXISTS (SELECT 1 FROM profiles WHERE profiles.id = user_games.user_id AND profiles.show_library = true AND profiles.is_public = true)`
  - INSERT/UPDATE/DELETE: `auth.uid() = user_id`
- Policies for `reviews`:
  - SELECT: `true` (public readable)
  - INSERT/UPDATE/DELETE: `auth.uid() = user_id`
- Policies for `ranked_lists`:
  - SELECT: `auth.uid() = user_id OR EXISTS (SELECT 1 FROM profiles WHERE profiles.id = ranked_lists.user_id AND profiles.show_rankings = true AND profiles.is_public = true)`
  - INSERT/UPDATE/DELETE: `auth.uid() = user_id`

Create `supabase/migrations/20261007000002_triggers_and_seed.sql`:
- Function and trigger `handle_new_user()` on `auth.users`:
  - Automatically inserts into `public.profiles` with `id`, `username`, and `display_name` extracted from user metadata or email prefix.
- Seed data for GOTY winners from 2014 to 2024 (Dragon Age: Inquisition, The Witcher 3, Overwatch, The Legend of Zelda: Breath of the Wild, God of War, Sekiro, The Last of Us Part II, It Takes Two, Elden Ring, Baldur's Gate 3, Astro Bot).
</description>
