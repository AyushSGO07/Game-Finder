<task id="2-01-01" wave="1">
<title>Define Game Metadata Pydantic Schemas</title>
<description>
Create `backend/app/schemas/game.py` defining schemas for game data structures:
- `GameCard`: minimal model for card displays (id, steam_appid, title, header_image, capsule_image, genres, rating, release_date).
- `ScreenshotItem`: screenshot thumbnail and full path.
- `MovieItem`: trailer name, thumbnail, and mp4/webm stream URLs.
- `GameDetail`: full game metadata including description, developers, publishers, system requirements, screenshots, trailers, and tags.
- `SteamSearchResult`: item list returned by Steam storesearch.
- `GameSearchResponse`: paginated search response model with total count, items, and page metadata.
Export these schemas in `backend/app/schemas/__init__.py`.
Create `backend/tests/test_game_schemas.py` to verify valid parsing and boundary validation.
</description>

<task id="2-01-02" wave="1">
<title>Implement Asynchronous TTL Cache Service</title>
<description>
Create `backend/app/services/cache_service.py`:
- Utilize `cachetools.TTLCache` wrapped in an async-compatible interface (`asyncio.Lock` for concurrency safety).
- Default configuration: `maxsize=1000`, `ttl=3600` (1 hour).
- Provide methods:
  - `get(key: str) -> Optional[Any]`
  - `set(key: str, value: Any, ttl: Optional[int] = None) -> None`
  - `delete(key: str) -> bool`
  - `clear() -> None`
  - `stats() -> dict` (hits, misses, currsize)
  - Helper `make_key(namespace: str, identifier: Union[str, int]) -> str`
Create `backend/tests/test_cache_service.py` to verify cache hits, misses, expiration, and stats tracking.
</description>
<verification>
`python -m pytest backend/tests/test_cache_service.py` passes.
</verification>
</task>

<task id="2-01-03" wave="1">
<title>Implement Steam Store Web API Client with Backoff and Caching</title>
<description>
Create `backend/app/services/steam_service.py`:
- Use `httpx.AsyncClient` with reusable session, 5.0s timeout, and connection limits.
- Endpoints:
  - Search: `https://store.steampowered.com/api/storesearch/?term={term}&l=english&cc=US`
  - Details: `https://store.steampowered.com/api/appdetails?appids={appid}&cc=US&l=english`
- Integrate `CacheService`:
  - Check cache before outbound call.
  - On 200 OK, cache result and return parsed data.
- Resiliency:
  - Retry on HTTP 429 / 5xx with exponential backoff (up to 3 retries, base delay 0.5s).
  - Handle invalid / unreleased AppIDs (`success: false`) cleanly by returning `None` instead of raising exceptions.
  - Ensure API keys are never required or leaked.
Create `backend/tests/test_steam_service.py` with mock responses (using `respx` or `unittest.mock`) testing search parsing, details parsing, 429 backoff, and cache utilization.
</description>
<verification>
`python -m pytest backend/tests/test_steam_service.py` passes.
</verification>
</task>
