<task id="2-02-01" wave="2">
<title>Implement Artwork & Metadata Fallback Service</title>
<description>
Create `backend/app/services/fallback_service.py`:
- Wikipedia media resolver:
  - Query Wikipedia action API (`action=query&prop=pageimages&format=json&piprop=original|thumbnail&pithumbsize=600&titles={game_title}`)
  - Extract high-resolution image URL when available.
- Stylized placeholder generator:
  - Generate title-derived placeholder artwork with dark gaming aesthetics (e.g., UI Avatars or custom SVG/gradient data URLs) when Wikipedia has no match.
- Provide method `resolve_fallback_metadata(title: str) -> GameCard` that guarantees non-empty artwork, title, and descriptive tags.
Create `backend/tests/test_fallback_service.py` to verify Wikipedia parsing, placeholder generation, and fallback guarantees.
</description>
<verification>
`python -m pytest backend/tests/test_fallback_service.py` passes.
</verification>
</task>

<task id="2-02-02" wave="2">
<title>Implement Unified Game Coordinator Service</title>
<description>
Create `backend/app/services/game_service.py`:
- Inject `SteamService`, `FallbackService`, and `CacheService`.
- Concurrency control:
  - Use `asyncio.Semaphore(5)` to bound concurrent outbound requests during batch enrichment.
- Methods:
  - `enrich_game(title: str, app_id: Optional[int] = None) -> GameCard`: attempts Steam lookup; falls back to FallbackService if Steam yields nothing.
  - `batch_enrich_games(titles: List[str]) -> List[GameCard]`: concurrently resolves and enriches multiple games.
  - `get_game_details(app_id: int) -> Optional[GameDetail]`: fetches full Steam details with fallback on missing fields.
  - `search_and_filter(query: str, genre: Optional[str] = None, min_rating: Optional[float] = None, page: int = 1, page_size: int = 10) -> GameSearchResponse`: searches Steam catalog, enriches, filters by genre/rating, and paginates.
Create `backend/tests/test_game_service.py` to verify enrichment coordination, semaphore concurrency limits, and filtering behavior.
</description>
<verification>
`python -m pytest backend/tests/test_game_service.py` passes.
</verification>
</task>

<task id="2-02-03" wave="2">
<title>Implement Games API Routes and Main App Integration</title>
<description>
Create `backend/app/api/v1/games.py`:
- Endpoints:
  - `GET /api/v1/games/search`: query parameter validation (`q: str`, `genre: Optional[str]`, `min_rating: Optional[float]`, `page: int = 1`, `page_size: int = 10`).
  - `GET /api/v1/games/{app_id}`: returns full `GameDetail`. Returns 404 if not found.
  - `POST /api/v1/games/batch`: accepts list of titles in JSON body `{"titles": ["Elden Ring", "Hades"]}` and returns list of enriched `GameCard`.
- Integrate router into `backend/app/main.py` under prefix `/api/v1/games` with tag `games`.
- Error handling: return sanitized 503 or 404 errors, never leaking internal tracebacks or API secrets.
Create `backend/tests/test_games_api.py` with FastAPI `TestClient` to test search, details, batch enrichment, 404s, and parameter validations.
</description>

`python -m pytest backend/tests/test_games_api.py` passes and full suite `python -m pytest backend/tests/` passes.
</verification>
